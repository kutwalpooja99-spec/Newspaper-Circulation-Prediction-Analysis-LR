# Newspaper-Circulation-Prediction-Analysis-LR
A Machine Learning project using Python and Linear Regression to analyze newspaper circulation data and predict Sunday newspaper circulation based on daily circulation.
## 📌 Project Overview

This project focuses on analyzing newspaper circulation data and predicting Sunday newspaper circulation based on daily newspaper circulation using the Linear Regression algorithm.

## 🎯 Project Objective

The main objective is to understand the relationship between daily and Sunday newspaper circulation and build a Machine Learning model to predict Sunday circulation.

## 📂 Dataset

- Dataset: NewspaperData.csv
- Total Records: 34
- Features:
  - Newspaper
  - Daily Circulation
  - Sunday Circulation

## 🛠️ Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## ⚙️ Project Workflow

1. Data Loading
2. Data Understanding
3. Missing Value Checking
4. Correlation Analysis
5. Data Visualization
6. Feature and Target Selection
7. Linear Regression Model Building
8. Prediction
9. Model Evaluation

## 🤖 Machine Learning Algorithm

**Linear Regression**

- Independent Variable (X): Daily Circulation
- Dependent Variable (Y): Sunday Circulation

## 📈 Model Evaluation

Evaluation metrics used:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
